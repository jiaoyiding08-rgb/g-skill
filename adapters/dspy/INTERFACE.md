# DSPy / GEPA 候选优化接口设计

**状态：接口设计，未接入 SDK，未运行优化。**

未来输入包含 skill_name、baseline_path/hash、开发输入集、开发评分反馈、可修改文件白名单、模型/成本/轮数限制。优化器不能读取真正留出集、密钥、私人数据库或正式安装目录。

输出为 candidate_path/hash、修改 diff、修改假设、开发集运行回执和预计风险。输出不包含正式发布动作。候选进入现有回归与人工评审，再由独立程序评估留出。

可借鉴 GEPA 使用文字反馈和执行结果改进候选的机制。人的执行结果与模型 benchmark 表现不是同一个指标；对本产品的帮助需另测。当前维护者可以手工修改候选，无需先安装优化器。

来源与许可证入口见 docs/open-source-map.md 中 DSPy/GEPA。未来真实集成时锁定 commit/包版本，增加接口测试、输入隔离、回退与成本中止测试。
